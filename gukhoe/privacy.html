개인정보처리방침

유튜브 댓글 자동 답글 도구 (오늘의국회) · 최종 수정 2026년 11월 13일

이 도구는 제작자가 자신의 유튜브 채널을 운영하려고 만들어 혼자 쓰는 개인용 프로그램입니다. 서버가 없고, 제작자 본인의 컴퓨터에서만 돌아갑니다. 다른 사용자를 받지 않으며 회원가입도 없습니다.

1. 어떤 정보를 다루나

정보어디서왜
내 채널 영상에 달린 공개 댓글 (작성자 표시 이름, 내용, 댓글 ID) YouTube Data API답글을 달기 위해
내 채널 ID·채널 이름YouTube Data API 내 채널이 맞는지 확인하기 위해
구글 로그인 토큰구글 OAuth 매번 로그인하지 않고 API를 쓰기 위해

이름·전화번호·주소·결제 정보 같은 것은 받지도, 저장하지도 않습니다.

2. 어디에 보관하나

전부 제작자 본인 컴퓨터 안에만 있습니다. 외부 서버로 보내지 않고, 데이터베이스를 따로 운영하지 않습니다. 구글 로그인 토큰은 그 컴퓨터의 파일 (token.json)로만 보관합니다.

3. 누구에게 넘기나

아무에게도 넘기지 않습니다. 판매·대여·공유·광고 활용을 하지 않습니다. 답글 초안을 만들 때 댓글 내용이 언어모델 서비스로 전달되며, 그 목적은 답글 작성 하나뿐입니다.

4. 얼마나 보관하나

  • 이미 답글을 단 댓글 ID — 같은 댓글에 두 번 답글을 달지 않으려고 보관합니다
  • 실행 기록(로그) — 문제가 났을 때 원인을 찾으려고 남깁니다
  • 구글 로그인 토큰 — 연결을 끊거나 파일을 지우면 사라집니다

필요 없어지면 해당 파일을 지우는 것으로 즉시 삭제됩니다.

5. 구글 사용자 데이터 정책

이 도구가 구글 API로 받은 정보의 사용과 다른 앱으로의 전송은 Google API Services User Data Policy를 따르며, 여기에는 제한적 사용(Limited Use) 요건이 포함됩니다.

6. 연결 끊기

구글 계정의 타사 앱 및 서비스에서 이 앱의 접근 권한을 언제든 취소할 수 있습니다. 취소하면 이 도구는 더 이상 댓글을 읽거나 답글을 달 수 없습니다.
